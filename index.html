Case study · AI implementation

An automated video studio with a model checking every step

ReplayForge is my YouTube channel that explains what is really behind AI headlines. I built the pipeline that produces it. It researches a topic, writes and fact-checks a script, records the narration, animates the visuals and packages a long video plus a vertical Short.

The hard part is trust. A second model from a different provider reviews each stage. If a stage still fails after three rounds, it stops and goes to a person, with the open issues listed. Nothing is published without a human.

Language
Python
Review rounds per gate
3 max
Output formats
16:9 and 9:16

  1. Research and script

    Pick or take a topic, gather sources, write the script and a beat list for the visuals.

    verifier gate: fact-check

  2. Narration

    Text-to-speech with written pacing markup, then automatic checks for clipped or garbled takes.

    verifier gate: audio

  3. Visuals

    Manim animations timed to the narration, rendered in landscape and vertical.

    verifier gate: video frames

  4. Package

    Mix, thumbnail and metadata go to a small approval web app I wrote.

  5. Human release

    A person reviews, uploads and schedules. Scheduled jobs and a monitoring service keep the server healthy.
